建設業のホームページに載せたいこと｜元請けと求職者に選ばれる構成

建設業の仕事は、紹介や長い付き合いから生まれることが多く、「ホームページはなくても困らない」と考えている会社もあります。けれども、新しい元請けや発注者は、取引を始める前に、相手の会社のことを調べます。働きたい人も、応募の前に会社のホームページを確かめます。

この記事では、建設業のホームページを見ている人が何を確かめているのか、何をどう載せればよいのかを紹介します。あわせて、地域と工事の種類で見つけてもらう工夫、紹介や協力会社募集などの仕事の取り方との関係、制作費用の考え方と制作会社の選び方もまとめました。土木、解体、設備工事、内装など、工事の種類が違っても、考え方は同じです。

建設業のホームページを見ている人

見ている人確かめていること
元請け・発注者許可の種類、施工実績、対応できる工事と地域、安全への取り組み
協力会社どんな工事を任せてもらえるか、取引の条件、連絡の方法
求職者仕事の内容、給与と休み、資格を取るための支え、働く人の様子
金融機関・取引先会社の概要、事業の内容、続けて営業しているか

建設業のホームページは、仕事を頼む人と、一緒に働きたい人の、両方に向けて作る必要があります。どちらか一方だけに向けた作りだと、もう一方の人は、知りたいことを見つけられずに離れてしまいます。

載せておきたい内容

建設業の許可と、資格を持つ人

国土交通省の説明では、建設工事は、土木一式工事と建築一式工事の2つの一式工事と、27の専門工事の、あわせて29の種類に分かれています。建設業の許可は、この業種ごとに受けるものです。許可の番号と、許可を受けている業種を載せておくと、どんな工事を請け負える会社かが、発注する側に一目で伝わります。

許可には、都道府県知事の許可と、国土交通大臣の許可があります。営業所が1つの都道府県の中だけにある場合は知事の許可、2つ以上の都道府県に営業所を置く場合は大臣の許可です。どちらの許可かも、許可の番号とあわせて書いておきましょう。

許可の有効期間は5年で、5年ごとに更新が必要です。更新したのにホームページの番号や年度が古いままになっていると、細かく見る発注者ほど気になります。更新のたびに、会社概要の欄も直す習慣をつけましょう。施工管理技士などの資格を持つ人の数も、会社の力を示す材料になります。

施工実績

発注する人が一番よく見るのが、施工実績です。この後の章で、くわしい書き方を紹介します。

対応できる工事と、地域

「〇〇市 解体工事」「〇〇市 外構工事」のように、地域と工事の種類で探されることが多い業種です。対応できる工事の種類と、対応している地域を、文章で具体的に書きましょう。保有している重機や車両も、対応できる工事の規模を伝える材料になります。

安全と品質への取り組み

安全のための朝礼、点検、教育など、ふだん行っていることを書きます。受けている表彰や認定があれば、あわせて載せます。現場の安全を大切にしている会社だと伝わることは、元請けにとっても、求職者にとっても安心材料になります。

ページの構成

建設業のホームページでは、次のような構成がよく合います。

協力会社の募集ページは、意外と見落とされがちです。募集する工事の種類、条件、連絡の方法を載せておくと、新しい取引の入口になります。ページ数の考え方は、ホームページは何ページ必要？で紹介しています。

施工実績の書き方

施工実績は、写真を並べるだけでは伝わりません。1件ごとに、次のことを添えましょう。

  • 工事の種類：新築、改修、解体、外構など
  • 場所：市区町村までで十分です
  • 規模：面積、階数、期間など、出せる範囲で
  • 担当した範囲：全体を請け負ったのか、一部の工事を担当したのか
  • 工夫したこと：狭い場所、短い工期、近隣への配慮など

施工写真を載せるときは、発注者によって扱いが違うため、載せる前に確かめることが必要です。建物や場所が特定されない写真を選ぶ、名前を出さずに工事の内容だけを書く、といった方法もあります。取引先の名前を出せないときの書き方は、製造業のホームページに載せたい「設備一覧」と「加工事例」の書き方も参考になります。

施工実績は、工事の種類ごと、地域ごとに探せるようにしておくと、発注する人が自分の工事に近い例を見つけやすくなります。件数が増えてきたら、「解体」「外構」「改修」のように分けて並べましょう。

地域と工事の種類で見つけてもらう工夫

建設業では、「地域の名前」と「工事の種類」を組み合わせて探す人が多くいます。ホームページを作るときは、この探し方に合わせて、ページと文章を用意しておくことが大切です。

工事の種類ごとに、ページを分ける

対応できる工事を1ページにまとめて並べるだけでは、それぞれの工事について十分に書けません。主な工事は、種類ごとにページを分け、次のことを書きます。

  • その工事で対応できる内容と、対応できない内容
  • 対応している地域
  • その工事の施工実績
  • 相談から工事が終わるまでの流れ
  • よく聞かれる質問と、その答え

ページの見出しや最初の文章には、「〇〇市・〇〇市の解体工事」のように、探す人が入れる言葉を自然に入れます。同じ言葉を不自然にくり返す必要はありません。読んだ人の疑問に答える中身を増やすことが、結果として検索でも見つけてもらいやすくなります。

対応地域を、文章で書く

「県内全域」とだけ書くより、よく工事をしている市区町村の名前を並べるほうが、探している人にも検索にも伝わります。地図の画像だけで示すと、文字として読み取られないため、文章でも書いておきましょう。

Googleマップに会社の情報を載せる

「近くの解体業者」のように探すと、地図と一緒に会社の情報が出てきます。ここに出てくるのが、Googleビジネスプロフィールです。無料で登録でき、会社の名前、電話番号、営業時間、写真、口コミなどを載せられます。

建設業のように、お客様のところへ出向いて仕事をする会社は、事務所の住所を表に出さず、「サービス提供地域」を設定することもできます。Googleのヘルプでは、事務所でお客様に対応していない場合は住所を載せず、サービス提供地域だけを入れるよう案内されており、地域は市区町村や郵便番号で20か所まで指定できます。整え方は、Googleマップで選ばれる会社の共通点とMEO対策とは？自分でできることと、頼むときの相場で紹介しています。

ホームページと、仕事の取り方の関係

建設業の仕事は、ホームページだけで取れるものではありません。けれども、ほかの取り方と組み合わせることで、ホームページが役に立つ場面はたくさんあります。

紹介を受けたとき

紹介を受けた会社は、連絡の前に、紹介された会社の名前で検索することが多いものです。ここでホームページが見つからない、情報が古い、となると、紹介してくれた人の信用にも関わります。紹介の仕事が多い会社ほど、会社のことが正しく分かるホームページを用意しておく意味があります。

協力会社を募集するとき

人手が足りないとき、新しい協力会社を探すこともあります。協力会社の募集ページがあれば、検索で見つけた会社や、知り合いから話を聞いた会社が、取引の条件を確かめてから連絡できます。募集する工事の種類、対応してほしい地域、支払いの条件、安全の決まりなどを書いておくと、合う会社から連絡が来やすくなります。

元請けとして仕事を探すとき

元請けの会社が新しい協力会社を探すときも、許可の業種、施工実績、保有している重機、対応できる地域を確かめます。協力会社として仕事を増やしたい場合は、この情報を分かりやすく載せておきましょう。

公共工事の入札に参加するとき

国や自治体の公共工事は、発注する機関が入札の情報を公表し、決められた手続きで請け負う会社を決めます。国土交通省の説明では、公共性のある工事を発注者から直接請け負おうとする建設業者は、「経営事項審査」という審査を必ず受けなければなりません。経営の状況や規模、技術の力などを、数値で評価する審査です。

入札の結果は、ホームページの有無で決まるものではありません。それでも、会社の情報を正しく載せておくことは、地域で事業をしている会社として、取引先や住民からの信用につながります。

無料相談業種に合ったホームページを作りたい方へ

業種ごとに、取引先や求職者が見るところは違います。現場の話が通じる担当が、構成から一緒に考えます。

採用ページで気をつけたいこと

建設業は、人手の確保に悩む会社が多い業種です。2024年4月からは、建設業にも時間外労働の上限規制が適用されました。厚生労働省の資料によると、建設の事業では、時間外労働は原則として月45時間・年360時間まで、特別な事情があって労使で合意した場合でも年720時間までなど、ほかの業種と同じ上限が適用されます。災害の復旧・復興の事業では、一部の決まりが適用されません。

休みの取り方や働き方を見直した会社は、それを採用ページでしっかり伝えましょう。

  • 職種ごとにページを分ける：施工管理と、現場の作業員では、知りたいことが違います。
  • 一日の流れを書く：朝の集合から現場の終わりまで、具体的に書きます。
  • 資格を取るための支えを書く：費用の補助、講習の時間の扱いなど、会社としての支えを書きます。
  • 休みと残業の実際を書く：週休の形、年間の休日数、残業のおおよその時間を、書ける範囲で具体的に。
  • 現場の写真と、先輩の声を載せる：どんな人と働くのかが伝わります。

採用ページの書き方は、採用ページで応募が増える書き方と求人を出しても応募が来ない中小企業へでもくわしく紹介しています。採用に一番困っている場合は、採用ページだけを先に作ることもできます。

制作費用の考え方

ホームページの制作費用は、ページの数、文章と写真を誰が用意するか、必要な機能などで決まります。建設業のホームページでは、特に次のところで費用に差が出ます。

  • 工事の種類ごとのページの数：工事の種類を分けて書くほど、ページが増えます。
  • 施工実績の載せ方：自分たちで足していける仕組みにするか、制作会社に頼んで載せるかで変わります。
  • 撮影：現場や重機、働く人の写真を新しく撮るかどうかで変わります。
  • 採用ページ：職種ごとにページを分ける、先輩の声を取材して書く、といった内容で変わります。

相場は、頼む内容や制作会社によって大きく違うため、一つの金額で言い切ることはできません。考え方の例として、マツケンスタジオの料金を紹介します。

ページ数建設業での使い方の例料金
1ページ（LP）協力会社の募集や、作業員の募集など、一つの目的に絞る15万円〜
2〜5ページ会社案内、対応できる工事、施工実績、問い合わせなど、まず必要なものをそろえる30万円〜
6〜20ページ工事の種類ごとのページや、職種ごとの採用ページまで用意する60万円〜

期間は、LPで数週間〜1か月ほど、会社のホームページで1〜3か月ほどが目安です。制作費のほかに、ドメインやサーバーの費用など、持ち続けるための費用もかかります。費用の内訳は、ホームページ制作の費用は何で決まる？とホームページの維持費・管理費の相場で紹介しています。

相談の前にそろえておくと、話が早いもの

  • 許可の番号と業種が分かる書類の写し
  • これまでの施工写真と、工事の種類・場所・規模のメモ
  • 保有している重機や車両の一覧
  • 資格を持つ人の人数と、資格の種類
  • 採用したい職種と、給与や休みの条件

すべてがそろっていなくても相談はできます。何があって何がないかが分かるだけで、必要なページの数や撮影の有無が決まり、見積りが具体的になります。依頼から公開までの流れは、ホームページ制作の流れと期間で紹介しています。

補助金を使うときの要点

ホームページの制作に、補助金を使えることがあります。よく調べられるのは、小規模事業者持続化補助金です。従業員の数などの条件に当てはまる小さな会社が、販路を広げるための取り組みの一部として、ホームページの制作費を申請できる制度です。

  • ホームページの費用だけでは申請できず、ほかの取り組みと組み合わせた計画にする必要があります。
  • 交付が決まる前に発注した費用は、対象になりません。
  • 補助金は後払いで、制作費をいったん全額支払う必要があります。
  • 申請しても、採択されるとは限りません。

制度の内容は公募の回ごとに変わります。くわしくは、ホームページ制作に使える補助金で紹介しています。申請の前には、必ず最新の公募要領を確かめてください。

制作会社の選び方

建設業のホームページを頼むときは、次の点を確かめておくと、あとで困ることが少なくなります。

  • 同じ業種のホームページを作ったことがあるか：許可の業種、施工実績、協力会社募集など、建設業ならではの内容を理解しているかで、打ち合わせの進み方が変わります。
  • 見積りの内訳が分かるか：「一式」だけでなく、ページの数、撮影、文章の作成、公開後の更新などが分かれているかを確かめます。見方はホームページの見積りの見方で紹介しています。
  • やり取りがしやすいか：現場に出ていて日中に電話を取れないこともあります。連絡の方法や、返事までの目安を先に聞いておきましょう。
  • ドメインとサーバーが誰の名義になるか：制作会社の名義になっていると、あとで制作会社を変えるときに困ることがあります。
  • 公開後の更新を誰がするか：施工実績を足していくなら、自分たちで更新できる仕組みか、頼める体制があるかが大切です。

マツケンスタジオでは、ドメインとサーバーはお客様の名義のまま進め、最初の相談から公開後まで同じ担当が対応します。くわしい選び方は、ホームページ制作会社の選び方で紹介しています。

更新を止めない工夫

建設業のホームページでよくあるのが、お知らせが何年も前のまま止まっていることです。今も営業しているのか分からない印象を与えてしまいます。

施工実績を、工事が終わるたびに1件ずつ足していくのが、無理のない更新の方法です。写真を数枚と、工事の種類・場所・規模をメモしておけば、まとめて載せることもできます。

現場が忙しく、自分たちで更新する時間が取れない会社も多いものです。マツケンスタジオでは、更新が難しい場合は、月額のサポートで代わりに更新することもできます。

まとめ

建設業のホームページは、元請けや発注者と、働きたい人の両方が見ています。許可と資格、施工実績、対応できる工事と地域、安全への取り組み、そして働く人の様子が伝わる構成にしましょう。地域と工事の種類で探されることが多いので、工事の種類ごとのページと、Googleマップの情報を整えておくと、見つけてもらいやすくなります。紹介や協力会社の募集など、ほかの仕事の取り方とも組み合わせて考えると、ホームページの役目がはっきりします。費用は、ページの数と、施工実績の載せ方、撮影や採用ページの内容で決まります。施工実績は工事が終わるたびに足していくと、会社の力が自然と伝わるホームページに育っていきます。業種ごとの制作の進め方は、建設業のホームページ制作のページで紹介しています。

Q
紹介の仕事ばかりですが、ホームページは必要ですか？

紹介を受けた会社も、取引の前にホームページで会社のことを確かめることが多いものです。また、採用のためにも、会社の様子が分かるホームページがあると、応募につながりやすくなります。

Q
施工写真がほとんどありません。

これからの工事で、着工前、工事中、完成後の写真を撮りためていくのがおすすめです。それまでは、作業の様子や、保有している重機、働く人の写真で会社の様子を伝えられます。

Q
許可の番号は、載せたほうがいいですか？

載せておくのがおすすめです。許可を受けている業種と、知事の許可か大臣の許可かもあわせて載せると、どんな工事を請け負える会社かが、発注する側にすぐ伝わります。更新したら番号の表示も直しましょう。

Q
協力会社の募集ページには、何を書けばいいですか？

募集する工事の種類、対応してほしい地域、取引の条件、連絡の方法を書きます。どんな会社と取引したいかを書いておくと、合う会社から連絡が来やすくなります。

Q
事務所の住所を出さずに、Googleマップに載せられますか？

事務所でお客様に対応していない場合は、住所を表に出さず、対応している地域を設定する方法があります。Googleのヘルプで最新の決まりを確かめてから設定しましょう。

Q
まず少ないページで作って、あとから増やせますか？

できます。最初は会社案内と施工実績、問い合わせなど必要なものから作り、工事の種類ごとのページや採用ページをあとから足していく進め方もあります。
