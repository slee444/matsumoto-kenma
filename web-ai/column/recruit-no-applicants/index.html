求人サイトに載せても、ハローワークに出しても、応募が来ない。来ても、面接の前に連絡が取れなくなる。人手が足りない中小企業にとって、切実な悩みです。

応募が来ない理由は、給与だけではありません。求職者は、応募の前にいろいろなことを確かめ、不安が残った会社には応募しません。この記事では、公的なデータで今の採用の状況を確かめたうえで、応募が来ないときに見直したいこと、求人媒体の選び方、応募が来たあとの対応、そして会社のホームページが果たす役目を紹介します。

データで見る、中小企業の採用のむずかしさ

「うちに魅力がないから応募が来ない」と思い込む前に、まず世の中全体の状況を知っておきましょう。応募が来ないのは、自社だけの問題とは限りません。

求職者1人あたりの求人の数

厚生労働省の「一般職業紹介状況」は、ハローワークでの求人と求職の数から「有効求人倍率」を毎月公表しています。有効求人倍率は、仕事を探している人1人に対して、求人が何件あるかを示す数字です。1倍を超えると、人よりも仕事の数のほうが多い状態です。

指標（令和8年8月分・季節調整値）数値
有効求人倍率1.18倍
正社員の有効求人倍率1.00倍
新規求人倍率2.06倍

出典：厚生労働省「一般職業紹介状況（令和8年8月分）」（令和8年10月2日公表）

全体では、求職者1人に1件以上の求人がある状態が続いています。求職者から見ると、いくつもの求人を比べて選べる状況です。比べられたときに、選ばれる理由があるかどうかが問われます。

大卒の新卒採用では、中小企業の求人が多い

新卒の採用では、会社の規模による差がはっきり出ています。リクルートワークス研究所の「第42回 ワークス大卒求人倍率調査（2026年卒）」（2025年4月24日公表）によると、2026年3月卒の大卒求人倍率は全体で1.66倍でした。従業員規模別に見ると、次のとおりです。

従業員の規模大卒求人倍率（2026年3月卒）
300人未満8.98倍
300〜999人1.43倍
1000〜4999人1.05倍
5000人以上0.34倍

出典：リクルートワークス研究所「第42回 ワークス大卒求人倍率調査（2026年卒）」

300人未満の会社では、民間企業への就職を希望する学生1人に対して、9件近い求人があったことになります。一方で、5000人以上の大きな会社では、希望する学生のほうが求人より多い状態でした。

なお、同じ研究所の「第43回 ワークス大卒求人倍率調査（2027年卒）」（2026年4月23日公表）では、全体の大卒求人倍率は1.62倍でした。この回から従業員規模別の求人倍率の公表は取りやめられ、求人の数だけが規模別に示されています。300人未満の会社の求人数は38.5万人で、前年より3.5％減っています。

これらの数字から分かるのは、中小企業は「求人を出せば人が来る」状況にはない、ということです。だからこそ、求人の中身と、会社のことの伝え方が大切になります。

求職者は、応募の前に何をしているか

求人を見つけた人が、すぐに応募するとは限りません。多くの場合、次のような流れで応募を決めます。

  1. 求人サイトやハローワークで、求人を見つける
  2. 気になった会社の名前で検索し、ホームページやGoogleマップを見る
  3. 口コミや、SNSの様子も確かめる
  4. 不安がなければ、応募する

つまり、求人の内容だけでなく、検索して出てくる会社の情報も、応募を決める材料になっています。求人で興味を持ってもらえても、会社のことが分からなければ、応募の手前で止まってしまいます。

よくある3つの勘違い

応募が来ない状態が続くと、「うちには無理だ」とあきらめたくなります。けれども、次のような思い込みが、見直しの手を止めていることがあります。

「知名度がないから、応募は来ない」

求職者の多くは、知っている会社だけを探しているわけではありません。職種、勤務地、通勤のしやすさ、休みの取り方などの条件で求人を探し、そこで初めて会社の名前を知ります。知名度がなくても、探している人の目に留まる言葉で求人を書き、会社のことが分かる情報をそろえておけば、応募の候補に入ることはできます。

「給与などの条件で大手に勝てないから、無理だ」

給与は大切ですが、応募を決める材料はそれだけではありません。家から近い、転勤がない、仕事を一から教えてもらえる、社長や先輩との距離が近い、任される範囲が広い。こうした中小企業ならではの良さは、書かなければ伝わりません。条件で並ばれても、ほかの点で「ここがいい」と思ってもらえる材料を、具体的に書き出してみましょう。

「求人媒体を増やせば、応募は増える」

求人を出す場所を増やせば、見てもらえる回数は増えます。けれども、求人の中身や、会社のことが分かる情報が足りないままだと、見た人が応募まで進みません。費用だけが増えることもあります。まずは今の求人の中身を見直し、そのうえで、探している人がいる場所に出すほうが、無駄が少なくなります。

応募が来ないときに見直したい6つのこと

1. 求人の言葉が、探す人の言葉と合っているか

求職者は、職種の名前で求人を探します。社内でしか使わない呼び方や、あいまいな職種名では、検索で見つけてもらえません。「製造スタッフ」より「金属加工の仕上げ作業」のように、何をする仕事かが分かる名前にしましょう。勤務地も、市区町村名や最寄りの駅名など、探す人が入れそうな言葉で書いておくと見つけてもらいやすくなります。

2. 給与と休みが、具体的に書かれているか

「経験により優遇」「当社規定による」だけでは、生活の見通しが立ちません。入社したときの給与の例、休みの日数と曜日、残業のおおよその時間を、書ける範囲で具体的に書きます。

2022年10月に施行された改正職業安定法では、求人の情報について、うそや誤解を生む書き方をしないこと、正確で最新の内容に保つことが、会社にも求められるようになりました。良く見せようとして実際と違うことを書くと、入社後の早い退職にもつながります。ありのままを、分かりやすく書くことが大切です。

3. 仕事の中身が、想像できるか

一日の流れ、扱うもの、最初に任される仕事、覚えていく順番。仕事の中身が想像できると、「自分にもできそうか」を判断できます。未経験の人を迎えたい場合は、特に大切です。

4. 働く人の顔が見えるか

どんな人と働くのかは、求職者が一番気にしていることの一つです。働く人の写真や、先輩の声があると、職場の雰囲気が伝わります。社員インタビューの作り方は、採用ページの社員インタビューの作り方で紹介しています。

5. 会社名で検索したときに、何が出てくるか

自社の名前で検索してみてください。ホームページが出てこない、出てきても情報が古い、採用のページがない。こうした状態だと、求人で興味を持った人の不安が残ります。Googleマップに出てくる会社の情報や写真も、あわせて確かめておきましょう。整え方は、Googleマップで選ばれる会社の共通点で紹介しています。

6. 応募が手軽にできるか

応募の方法が電話だけ、入力する項目が多すぎる、返事が遅い。応募の手間が大きいと、途中でやめる人が増えます。電話のほかにフォームやメールでも応募でき、応募があったらすぐに連絡する流れを決めておきましょう。

求人媒体の種類と、選び方

求人を出す場所には、いくつかの種類があります。どれが一番良いということはなく、探している人がどこで仕事を探しているかで選びます。

種類特徴気をつけたいこと
ハローワーク無料で求人を出せる。地元で仕事を探す人が多く見ている決まった項目の中で書くため、会社の違いが伝わりにくい
求人サイト（掲載型）多くの人に見てもらえる。写真や長めの文章も載せられる掲載の期間ごとに費用がかかるものが多い
求人検索エンジンいろいろなサイトの求人をまとめて探せる仕組み。無料で載せられる枠があるものもある有料の枠を使う場合は、表示やクリックの数で費用が決まるものが多い
紹介（社員・取引先など）会社のことを知る人からの紹介なので、入社後のずれが少ない数は多く見込めない
人材紹介会社条件に合う人を探して紹介してもらえる採用が決まったときに費用がかかる形が多い
SNSふだんの職場の様子を、続けて伝えられる続けて投稿する手間がかかる。すぐに応募が増えるとは限らない
自社の採用ページ載せる量や書き方に決まりがなく、会社のことを十分に伝えられるそれだけでは見つけてもらいにくく、ほかの媒体とつなぐ必要がある

選ぶときの考え方

  • どんな人を採りたいかを先に決める：地元で長く働ける人か、経験のある人か、若い人か。採りたい人によって、見ている媒体が違います。
  • 無料で出せるところから始める：ハローワークや、無料の枠がある求人検索エンジンから始め、反応を見てから費用をかけるかを決めると、無駄が少なくなります。
  • 応募がどこから来たかを記録する：応募があったら、何を見て応募したかを聞いて記録しておきます。どの媒体が自社に合っているかが分かり、次の判断がしやすくなります。
  • どの媒体でも、会社のホームページにつなぐ：どこで見つけてもらっても、最後に会社のことを確かめる場所は会社のホームページです。

採用の時期による違い

採用には、時期によって動きが決まっているものがあります。新卒の採用は、国が日程の目安を示しています。

対象主な日程
大学生など（2027年度に卒業・修了する人）広報活動の開始は3月1日以降、採用選考活動の開始は6月1日以降、正式な内定日は10月1日以降
高校生（2027年3月に卒業する人）ハローワークでの求人申込みの受付開始は6月1日、学校への求人申込みと学校訪問の開始は7月1日、応募書類の提出の開始は9月5日（沖縄県は8月30日）、選考と内定の開始は9月16日

出典：内閣官房・文部科学省・厚生労働省・経済産業省による就職・採用活動日程の要請、厚生労働省「令和9年3月新規高等学校卒業者の就職に係る採用選考開始時期等について」

高校生の採用では、学校を通して求人を出すため、この日程に間に合うように求人票と会社の情報を用意しておく必要があります。生徒や先生、保護者が会社のことを確かめるときにも、会社のホームページが見られます。

経験者や中途の採用には、決まった日程はありません。応募が増える時期は、職種や地域によっても違います。自社の求人に、月ごとに何件の応募があったかを記録しておくと、自社に合った求人の出し方が見えてきます。「出してすぐに応募がないから失敗」と決めず、数か月の単位で見ていきましょう。

応募が来たあとの対応で、差がつく

せっかく応募が来ても、そのあとの対応で辞退されてしまうことがあります。求職者は、同時にいくつかの会社に応募していることが多いためです。

返事はできるだけ早く

応募から連絡までが空くほど、ほかの会社の選考が先に進み、気持ちが離れていきます。応募があったら、その日のうちか、遅くとも次の営業日には連絡するのが目安です。担当者が現場に出ていて連絡できない日があるなら、受け付けたことを伝える返事だけでも先に送れるようにしておきましょう。

面接の日程は、相手に合わせやすく

働きながら仕事を探している人は、平日の昼に時間を取りにくいものです。夕方や土曜日も選べるようにする、候補日をいくつか出す、といった工夫で、日程の調整で止まることが減ります。会社の場所、駐車場の有無、当日の持ち物、受付での名乗り方も、先に伝えておくと安心してもらえます。

職場の見学を用意する

現場のある仕事では、面接の前後に職場を見てもらうと、入社後の思い違いが減ります。どんな場所で、どんな人と、どんな作業をするのかが分かると、応募した人も働く姿を想像できます。見学ができることを、採用ページや求人に書いておくのもおすすめです。

選考のしかたを見直す

  • 面接の回数：面接が何回もあると、その間にほかの会社に決まってしまうことがあります。回数を減らせないかを考えます。
  • 出してもらう書類：最初から多くの書類を求めると、応募の手前でやめる人が増えます。最初は簡単な情報だけにする方法もあります。
  • 面接で伝えること：面接は、会社が選ぶ場であると同時に、応募した人が会社を選ぶ場でもあります。仕事の大変なところも含めて、正直に伝えましょう。
  • 結果の連絡：結果をいつまでに伝えるかを面接の場で伝え、その日までに連絡します。

応募してくれた人への対応は、採用の結果に関わらず、会社の印象として残ります。地域で事業をしている会社ほど、ていねいな対応が大切です。

会社のホームページが、応募を後押しする理由

求人サイトには、決まった形と文字数があり、会社ごとの違いを伝えきれません。会社のホームページなら、求人サイトに書ききれないことを、写真と一緒に十分に伝えられます。

  • 会社が実在し、きちんと営業していることが分かる：所在地、事業の内容、実績が載っていると、安心して応募できます。
  • 職場の様子が伝わる：建物、作業の場所、働く人の写真で、通う姿を想像できます。
  • 家族にも見せられる：転職を家族に相談するとき、会社のホームページを見せる人もいます。

求人サイトで見つけてもらい、会社のホームページで安心してもらう。この2つがそろうと、応募につながりやすくなります。

採用ページに載せておきたいこと

会社のホームページの中に、採用のページを用意しましょう。最低限、次の内容があると、求職者の疑問にひととおり答えられます。

  • 仕事の内容と、一日の流れ
  • 入社してから覚えていく流れ
  • 給与の例、休み、福利厚生
  • 働く人の写真と、先輩の声
  • 職場の写真
  • 応募の方法と、応募のあとの流れ（返事までの目安、面接の回数、見学ができるか）

書き方のくわしいポイントは、採用ページで応募が増える書き方で紹介しています。マツケンスタジオでは、採用に一番困っている会社のために、採用ページだけを先に作ることもできます。

求人サイトと、ホームページをつなげる

求人サイトの会社紹介の欄に、ホームページのアドレスを載せておきましょう。反対に、ホームページの採用ページからは、求人サイトの応募画面に進めるようにしておくと、応募の手間が減ります。

求人サイトの中には、無料で求人を載せられる枠を用意しているものもあります。採用ページを整えておけば、こうした求人サイトから来た人にも、会社のことをしっかり伝えられます。

採用ページは、作って終わりではありません。給与や休みの条件が変わったら、すぐに直します。古い情報が残っていると、求人と内容が食い違い、応募した人を迷わせてしまいます。自分たちで更新するのが難しい場合は、制作会社に任せる方法もあります。マツケンスタジオでは、月額のサポートで、更新を代わりに行うこともできます。

まとめ

公的なデータを見ても、中小企業が人を採りにくい状況は続いています。だからこそ、求人を出すだけで待つのではなく、見直せるところから手を入れることが大切です。求人の言葉、給与と休みの書き方、仕事の中身、働く人の顔、会社名で検索したときの見え方、応募の手軽さを見直しましょう。求人媒体は、採りたい人がいる場所を選び、応募がどこから来たかを記録します。応募が来たら、早く返事をし、面接や見学の調整を相手に合わせやすくします。求人で見つけてもらい、会社のホームページで安心してもらい、ていねいな対応で入社につなげる。この流れを作ることが、応募を増やす近道です。

よくある質問

Q
給与を上げないと、応募は増えませんか？

給与は大切ですが、それだけで決まるわけではありません。仕事の中身、一緒に働く人、休みの取り方などが分かると、応募を決めやすくなります。まずは、今の条件を具体的に伝えるところから見直してみてください。

Q
採用ページだけを、先に作ることはできますか？

できます。採用に一番困っている場合は、採用ページから作り、あとで会社のホームページ全体を整えていく進め方もあります。

Q
社員の写真を載せるのに抵抗がある人がいます。

本人の同意がないまま載せるのは避けましょう。後ろ姿や手元、作業の様子など、顔が写らない写真でも、職場の雰囲気は伝えられます。

Q
ハローワークの求人にも、ホームページは役立ちますか？

役立ちます。ハローワークの求人を見た人も、会社の名前で検索して、ホームページを確かめることがあります。求人票に会社のホームページのアドレスを載せておきましょう。

Q
求人媒体は、いくつに出せばいいですか？

数より、採りたい人が見ている場所かどうかが大切です。まずは無料で出せるところから始め、応募がどこから来たかを記録して、合う媒体に絞っていくと無駄が少なくなります。

Q
応募があっても、面接に来ない人がいます。

応募から連絡までの時間を短くし、面接の日程を選びやすくすると減ることがあります。会社の場所や当日の流れを先に伝えておくと、応募した人の不安も小さくなります。
