ウェブアクセシビリティの義務化とは？中小企業のサイトで何をすればいいか

「2024年4月から、民間企業もホームページのアクセシビリティ対応が義務になったと聞いた」「うちの会社のサイトも、今すぐ直さないといけないのか」。こうした相談を受けることが増えました。ネット上でも「ウェブアクセシビリティ義務化」という言葉をよく見かけます。

ただ、法律で義務になったことと、努力義務のままのことは分けて考える必要があります。この記事では、内閣府やデジタル庁が公開している情報をもとに、何が変わったのかを整理し、そのうえで中小企業のサイトでまずできることと、点検の方法を、制作する側の目線で紹介します。法律の判断が必要な場面では、専門家や公式の窓口に確かめてください。

ウェブアクセシビリティとは

ウェブアクセシビリティは、ホームページを誰でも使える状態にしておくことです。目が見えにくい人、耳が聞こえにくい人、手が不自由でマウスが使いにくい人、高齢で小さい文字が読みにくい人など、いろいろな人が同じ情報にたどり着けるようにします。

たとえば、目が見えない人は、画面の文字を音声で読み上げるソフト（スクリーンリーダー）を使ってホームページを見ています。このとき、写真に説明の文字が付いていないと、そこに何が写っているのか分かりません。マウスを使えない人は、キーボードだけで操作します。ボタンがキーボードで押せない作りだと、問い合わせフォームを送れません。

アクセシビリティは、障害のある人だけのためのものでもありません。屋外の明るい場所でスマートフォンを見る人、音を出せない電車の中で動画を見る人、老眼で細い文字が読みにくい人にとっても、見やすく使いやすいサイトになります。

「義務化」と言われるのは何か

「義務化」の話のもとになっているのは、障害者差別解消法の改正です。内閣府の障害者白書によると、改正法は2021年6月に公布され、2024年4月1日に施行されました。

義務になったのは「合理的配慮の提供」

改正の大きな点は、事業者による「合理的配慮の提供」が、それまでの努力義務から義務に改められたことです。行政機関などは、改正前から義務とされていました。

合理的配慮とは、障害のある人から「こうしてほしい」という申し出（意思の表明）があったときに、負担が重すぎない範囲で、困りごと（社会的なバリア）を取り除くための対応をすることです。ホームページに置きかえると、たとえば次のような場面が考えられます。

  • 「フォームが読み上げソフトでうまく使えないので、メールで問い合わせたい」と言われた
  • 「PDFの資料が読めないので、文字の形で送ってほしい」と頼まれた
  • 「動画の内容を文章で教えてほしい」と相談された

こうした申し出に、個別に話し合いながら対応するのが合理的配慮です。負担が重すぎるかどうかは、事業への影響や実現できるかなどを考えて、一件ずつ総合的に判断するとされています。重すぎると判断した場合も、理由を丁寧に説明し、理解を得るよう努めることが望ましいとされています。

サイトを前もって整えるのは「環境の整備」で、努力義務

一方、不特定多数の人に向けて、前もってサイトを使いやすく整えておくことは「環境の整備」にあたります。障害者白書では、環境の整備は行政機関などと事業者の努力義務とされ、その例に「情報アクセシビリティの向上」があげられています。

デジタル庁のニュース記事でも、2024年4月から民間事業者も合理的配慮の提供が義務になったこと、合理的配慮を的確に行うための環境の整備は努力義務であることが説明されています。

項目どういうことか事業者の扱い
合理的配慮の提供申し出があったときに、個別に対応すること2024年4月1日から義務
環境の整備前もって、誰でも使えるように整えておくこと（サイトの対応はここに入る）努力義務

誤解されやすい点

つまり、「2024年4月から、すべての民間企業のサイトがアクセシビリティ規格に合っていないといけなくなった」という意味ではありません。見出しだけを見ると、そう読めてしまう記事もあるので注意が必要です。

とはいえ、「努力義務だから何もしなくてよい」とも言えません。サイトが使いにくいままだと、申し出があるたびに個別の対応が必要になります。前もって整えておけば、困る人が減り、個別の対応も少なくてすみます。白書でも、環境の整備は合理的配慮の基礎になるもので、両方を両輪として進めることが大切だとされています。

また、デジタル庁のニュース記事では、障害を理由にサービスの提供を断ったり、制限をつけたりする「不当な差別的取扱い」は禁止されている点にもふれています。法律の細かい扱いや罰則などは、内閣府の障害者差別解消法のページで最新の情報を確かめてください。

JIS X 8341-3とWCAGの関係

アクセシビリティ対応を調べると、「JIS X 8341-3」と「WCAG（ダブリューキャグ）」という二つの名前が出てきます。

名前何か
WCAGウェブの標準を決める国際的な団体（W3C）が出している、ウェブのアクセシビリティの指針。改訂が重ねられ、2.0、2.1、2.2と版がある
JIS X 8341-3:2016日本の規格（JIS）。デジタル庁の資料では、WCAG 2.0と同じ内容の規格とされている

どちらも、「画像に代替テキストを付ける」「文字と背景の色の差を十分にとる」のような、守るべき項目（達成基準）が並んでいます。項目には、レベルA、AA、AAAの三つの段階があり、Aが最低限、AAがその上、AAAがさらに高い段階です。

デジタル庁は、JIS X 8341-3に準拠することを前提にアクセシビリティを進めていて、はじめて取り組む行政職員や事業者向けに「ウェブアクセシビリティ導入ガイドブック」を公開しています（2025年10月16日の版が出ています）。専門用語を減らし、図を多く使った内容なので、担当者が最初に読む資料として向いています。

新しいWCAG 2.1や2.2には、スマートフォンでの操作などに関わる項目が追加されています。JISに合わせながら、WCAGの新しい項目にも取り組むことはできます。ただ、中小企業がはじめから全部を目指す必要はありません。まずは、影響の大きいところから直していくのが現実的です。

中小企業のサイトでまずできる7つのこと

ここからは、制作の現場で直すことが多く、効果も分かりやすいところを紹介します。どれも、サイトを作り直さなくても、今のページを少しずつ直していけるものです。

1. 画像に代替テキストを付ける

代替テキストは、画像の代わりに読み上げられる説明の文字です。HTMLでは「alt属性」と呼ばれます。読み上げソフトを使う人は、これを聞いて画像の中身を知ります。

  • 工場や製品の写真なら「〇〇工場の外観」「〇〇の製品写真」のように、何が写っているかを短く書く
  • 文字が入った画像（バナーや図）は、画像の中の文字と同じ内容を入れる
  • 飾りだけの線や模様は、読み上げないよう空にしておく

「画像1」「IMG_0012」のような名前が入ったままになっているサイトもよく見かけます。WordPressなどでは、画像ごとに代替テキストを入れる欄があります。

2. 文字と背景の色の差を十分にとる

薄いグレーの文字を白い背景に置くと、おしゃれに見えますが、読みにくくなります。WCAGでは、レベルAAの基準として、文字と背景の明るさの差（コントラスト比）を、通常の文字で4.5対1以上、大きな文字で3対1以上とすることが定められています。

色の差は、無料のコントラストチェックツールに色の値を入れると確かめられます。写真の上に文字を重ねている部分は、特に読みにくくなりやすいところです。また、「赤字の項目は必須」のように、色だけで意味を伝えるのも避け、「必須」と文字でも書きます。

3. 見出しを順番どおりに使う

読み上げソフトを使う人は、見出しを飛びながらページの中身をつかみます。見出しは、大見出し（h1）、中見出し（h2）、小見出し（h3）と、順番どおりに入れ子にします。

よくあるのは、「文字を大きくしたいから」という理由で見出しのタグを使ったり、逆に見出しなのに太字にしただけだったりするケースです。見た目と構造を分けて考えると、検索エンジンにもページの内容が伝わりやすくなります。

4. リンクの文言で行き先が分かるようにする

「こちら」「詳しくはここ」というリンクは、前後の文を読まないと行き先が分かりません。読み上げソフトでは、リンクだけを一覧で聞くこともあるため、「こちら」が並ぶと区別がつきません。

「会社案内のPDFをダウンロード」「採用情報を見る」のように、リンクの文字だけで行き先が分かる書き方にします。PDFや別のサイトに移るリンクは、そのことも書いておくと親切です。

5. フォームの入力欄に項目名を付ける

問い合わせフォームは、会社にとって一番大事なページの一つです。入力欄の中に薄い文字で「お名前」と書いてあるだけ（入力すると消える）の作りは、読み上げソフトで項目名が伝わらなかったり、入力中に何の欄か分からなくなったりします。

  • 入力欄ごとに、見えるところに項目名（ラベル）を付ける
  • 必須の項目は、色だけでなく「必須」と文字で書く
  • 入力に間違いがあったときは、どの欄の何が違うのかを文字で知らせる
  • 画像の文字を読み取らせる認証など、使えない人がいる仕組みには代わりの方法を用意する

フォームの近くに電話番号やメールアドレスも書いておくと、フォームが使いにくい人も問い合わせできます。問い合わせが少ないときの見直し方は、ホームページから問い合わせが来ない理由でも紹介しています。

6. 動画に字幕を付ける

工場の紹介や作業の様子を動画で見せる会社が増えています。音声で説明している動画は、耳が聞こえにくい人には内容が伝わりません。音を出せない場所で見ている人も同じです。

YouTubeなどには字幕を付ける機能があります。自動で付く字幕は間違いが出ることがあるので、確かめて直してから公開します。動画の要点をページの文章でも書いておくと、動画を見られない人にも伝わります。

7. PDFだけに頼らない

会社案内、製品カタログ、価格表などを、PDFだけで載せているサイトは少なくありません。紙のデータをスキャンしたPDFは、文字が画像になっていて読み上げられず、スマートフォンでは拡大しないと読めません。

大事な情報は、ページの本文（HTML）にも書くのがおすすめです。PDFは「印刷したい人向けの資料」として添える形にすると、検索にも見つかりやすくなります。ページに載せる文章や写真の準備は、ホームページに載せる写真と文章の用意のしかたを参考にしてください。

自社サイトの簡単な点検方法

専門の試験をしなくても、担当者が自分で確かめられることはあります。デジタル庁のニュース記事でも、キーボードだけで操作してみることや、読み上げを実際に試すことがすすめられています。次の点検を、トップページ、主なサービスのページ、問い合わせフォームの三つから始めてみてください。

点検することやり方見るところ
キーボードだけで使えるかマウスを使わず、Tabキーで進み、Enterキーで押すメニューやボタンにたどり着けるか。今どこを選んでいるかが見えるか。フォームを送れるか
読み上げで分かるかパソコンやスマートフォンに入っている読み上げ機能を使う画像の説明、リンクの文言、フォームの項目名が伝わるか
拡大しても読めるかブラウザで200％ほどに拡大する。スマートフォンで指で広げる文字が切れたり、重なったりしないか
色の差は十分かコントラストチェックツールに文字と背景の色を入れる薄い文字、写真の上の文字
見出しの順番ブラウザの拡張機能などで見出しの一覧を出すh1→h2→h3の順になっているか
画像・動画・PDFページを一つずつ見ていく代替テキスト、字幕、PDFだけの情報がないか

点検ツールには、Googleが無料で提供している「Lighthouse」（Chromeの開発者ツールに入っています）のように、ページを自動でチェックしてくれるものもあります。ただ、自動のチェックで分かるのは一部です。代替テキストの中身が合っているか、リンクの文言が分かりやすいかなどは、人の目で確かめる必要があります。

点検して見つかったことは、表にまとめて「すぐ直せるもの」「制作会社に頼むもの」に分けておくと、進めやすくなります。サイトの古さや直す箇所が多い場合は、ホームページのリニューアルを考えたい6つのサインもあわせて見てください。

ウェブアクセシビリティ方針の書き方の考え方

ウェブアクセシビリティ方針は、「自社のサイトで、どこまでを、どの基準で、いつまでに対応するか」を示すページです。官公庁や自治体のサイトではよく見かけますが、民間企業でも載せる会社が出てきています。法律で載せることが決められているものではありませんが、取り組む姿勢と、困ったときの連絡先を示せます。

書く項目

ウェブアクセシビリティ基盤委員会（WAIC）が公開している「ウェブアクセシビリティ方針策定ガイドライン」では、JIS X 8341-3に沿って方針を作る場合、次の項目をあげています。

項目書く内容扱い
対象範囲どのサイトが対象か。ドメインやURLで示す。原則はサイト全体必須
目標とする適合レベルレベルA、AA、AAAのどれを目指すか必須
目標とする対応度「準拠」「一部準拠」「配慮」のどれを目指すか推奨
目標を達成する期限いつまでに対応するか推奨
担当部署・連絡先問い合わせ先の部署名、できれば電話やメール推奨
分かっている問題点今残っている問題と、どう対応するか推奨

「準拠」「一部準拠」「配慮」は、JISへの対応の度合いを示す言葉です。「準拠」と「一部準拠」は、試験をしたうえで使う表記とされています。「配慮」は、JISを使って作ったことを示す表記で、試験をしたかどうかは問われません。どの言葉を使うかは、WAICの「対応度表記ガイドライン」で決まりを確かめてから選びます。

中小企業が書くときのポイント

  • できることを書く：はじめから高い目標を書くより、今の状態と、これから直す予定を正直に書くほうが信頼されます。
  • 連絡先をはっきり書く：使いにくいところがあったときに、どこへ連絡すればよいかが分かれば、合理的配慮の申し出も受けやすくなります。
  • 段階的に広げてよい：まずは主なページから対応し、ほかのページは時期を書いて順に広げる、という書き方もガイドラインで示されています。
  • 見直す日を書く：方針は一度書いて終わりではなく、点検のたびに更新します。

方針のページは、プライバシーポリシーと同じように、フッターなどから行けるところに置くのが一般的です。プライバシーポリシーの作り方はプライバシーポリシーの書き方で紹介しています。

無理なく進める順番

アクセシビリティ対応は、いっぺんに全部やろうとすると止まってしまいがちです。中小企業のサイトなら、次の順番で進めると取り組みやすくなります。

  1. 点検する：トップページ、主なサービスのページ、問い合わせフォームを、先ほどの方法で確かめる。
  2. すぐ直せるものから直す：代替テキスト、リンクの文言、PDFだけの情報など、文章の追加や修正で直せるもの。
  3. 作りに関わるものを直す：色の組み合わせ、見出しの構造、フォームの作りなど。制作会社に相談することが多いところです。
  4. 申し出の窓口を決める：使いにくいと言われたときに、誰がどう対応するかを社内で決めておく。
  5. 方針を書いて、定期的に見直す：新しいページを足すときも、同じ点を確かめる習慣にする。

新しいページやお知らせを足すたびに、代替テキストやリンクの文言を気にかけるだけでも、サイト全体の状態は少しずつよくなります。更新の頻度の考え方は、ホームページの更新頻度はどれくらい？の記事も参考にしてください。

マツケンスタジオでは、作り直しだけでなく、公開後の更新や改善も続けて受け持てます。社内で更新するのが難しい場合は、月額のサポートで代わりに更新することもできます。最初の相談から公開後まで同じ担当が受け持つので、「どこから直せばいいか分からない」という段階からでも相談できます。

まとめ

2024年4月1日に施行された改正障害者差別解消法で、民間の事業者も「合理的配慮の提供」が義務になりました。一方、サイトを前もって誰でも使えるように整える「環境の整備」は、努力義務とされています。「すべての会社のサイトが規格に合っていないといけなくなった」という意味ではありませんが、前もって整えておくほど、困る人も個別の対応も減らせます。

まずは、画像の代替テキスト、文字と背景の色の差、見出しの順番、リンクの文言、フォームの項目名、動画の字幕、PDFだけに頼らないこと。この七つを、主なページから点検してみてください。キーボードだけで操作してみる、読み上げ機能で聞いてみる、という簡単な確かめ方でも、多くのことが分かります。法律の扱いで迷うときは、内閣府やデジタル庁の公式の情報を確かめ、必要に応じて専門家に相談してください。

よくある質問

Q
民間企業のホームページもアクセシビリティ対応が義務になったのですか？

2024年4月1日に施行された改正障害者差別解消法で義務になったのは、障害のある人から申し出があったときに対応する合理的配慮の提供です。サイトを前もって誰でも使えるように整えることは環境の整備にあたり、内閣府の障害者白書では努力義務とされています。法律の扱いで迷う場合は、内閣府の公式情報を確かめ、専門家に相談してください。

Q
努力義務なら、何もしなくても問題ないですか？

努力義務は、対応に努めることが求められているものです。サイトが使いにくいままだと、申し出があるたびに個別の対応が必要になります。前もって整えておくほど、困る人も個別の対応も減らせるので、影響の大きいページから少しずつ進めるのがおすすめです。

Q
JIS X 8341-3とWCAGは、どちらに合わせればよいですか？

デジタル庁の資料では、JIS X 8341-3:2016はWCAG 2.0と同じ内容の日本の規格とされています。国内ではJISを基準に方針を書くことが多く、そのうえでWCAG 2.1や2.2で追加された項目に取り組むこともできます。中小企業は、まず代替テキストや色の差など影響の大きい点から始めるとよいでしょう。

Q
自社のサイトがどれくらい対応できているか、自分で確かめられますか？

マウスを使わずTabキーとEnterキーだけで操作できるか、パソコンやスマートフォンの読み上げ機能で画像の説明やリンクが伝わるか、拡大しても文字が切れないかなどは、担当者でも確かめられます。自動の点検ツールも役立ちますが、分かるのは一部なので、人の目での確認と組み合わせます。

Q
ウェブアクセシビリティ方針は載せないといけませんか？

法律で掲載が決められているものではありません。ただ、対象範囲、目指す基準、期限、連絡先を書いておくと、取り組む姿勢と困ったときの窓口を示せます。書く項目は、ウェブアクセシビリティ基盤委員会の方針策定ガイドラインが参考になります。

Q
アクセシビリティ対応のために、サイトを作り直す必要がありますか？

代替テキスト、リンクの文言、PDFだけの情報をページの文章にするなどは、今のサイトのまま直せることが多いです。色の組み合わせやフォームの作りなど、作りに関わる部分は直し方によって手間が変わるので、点検の結果を見てから、直すか作り直すかを考えます。
