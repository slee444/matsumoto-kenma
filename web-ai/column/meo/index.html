「MEO対策しませんか？」という営業の電話を受けたことがある方も多いのではないでしょうか。MEOは、地域で仕事をする会社にとって大切な取り組みですが、言葉だけが先に広まって、何をすればいいのか分かりにくくなっています。

この記事では、MEO対策とは何か、自分でできること、効果の見方、頼むときの費用の考え方と気をつけたい営業までをまとめます。

MEO対策とは

MEOは「マップエンジン最適化」の略で、Googleマップで自社を見つけてもらいやすくするための取り組みのことです。海外では「ローカルSEO」と呼ばれることが多く、日本では「MEO」という呼び方が広く使われています。

「〇〇市 工務店」「近くの 運送会社」のように、地域と業種で探したとき、検索結果の上のほうに地図と一緒に会社が並ぶことがあります。ここに表示されると、地域で依頼先を探している人の目にとまりやすくなります。

Googleマップに出る会社の情報は、「Googleビジネスプロフィール」という無料の仕組みで管理します。MEO対策の中心は、このビジネスプロフィールを正しく、充実した状態に保つことです。

SEOとの違い

SEOMEO
目的検索結果で、ホームページを上のほうに出すGoogleマップや地図の枠で、会社を上のほうに出す
整えるものホームページの中身や構成Googleビジネスプロフィールの情報、写真、口コミ
探す人地域にかぎらず、情報を調べている人地域で依頼先を探している人
大きく関わることページの内容の分かりやすさ、役に立つか探している人からの距離、情報の正しさ、口コミ

ただし、まったく別のものではありません。Googleマップで会社を見つけた人の多くは、次にホームページを見て依頼するかを決めます。両方をそろえて整えることで、効果が出やすくなります。

MEO対策のよいところと、注意したいところ

よいところ

  • 無料で始められる：ビジネスプロフィールの登録と利用には費用がかかりません。
  • 地域で探している人に届く：「〇〇市 外構工事」のように、地域で依頼先を探している人は、すでに頼む先を決めようとしていることが多いです。
  • 電話や道順にすぐつながる：Googleマップから、そのまま電話をかけたり、場所を調べたりできます。
  • 会社の様子が伝わる：写真や口コミで、ホームページを見る前に、会社の雰囲気を知ってもらえます。

注意したいところ

  • 距離は変えられない：探している人の場所から遠い会社は、どれだけ整えても上に出にくいことがあります。
  • 口コミは自分で書けない：口コミはお客様に書いてもらうものなので、すぐには増えません。厳しい口コミが書かれることもあります。
  • 続ける手間がかかる：写真や投稿、口コミへの返信は、続けてこそ意味があります。担当を決めないと、止まってしまいがちです。

Googleマップの表示で大事なこと

Googleは、地域の検索結果の順番について、主に「関連性」「距離」「知名度」の3つをもとに決めていると説明しています。

  • 関連性：探されている内容と、登録された情報がどれだけ合っているか。
  • 距離：探している人や、検索した地域からの近さ。
  • 知名度：会社がどれだけ知られているか。ウェブ上での情報や、口コミの数なども関わります。

距離は変えられませんが、関連性と知名度は、取り組み次第で高めていけます。Googleは、表示を良くするために、オーナー確認をする、情報を正しく新しく保つ、口コミに返信する、写真を足す、といったことを勧めています。また、お金を払って順位を上げる仕組みは受け付けていないと明記しています。

自分でできる7つのこと

MEO対策の多くは、無料で、自分たちでできます。

  1. Googleビジネスプロフィールに登録し、オーナー確認をする：まずは持ち主として管理できる状態にします。すでに自社の情報が出ている場合は、新しく作らず、その情報のオーナー確認をします。
  2. 基本情報をそろえる：会社名、住所、電話番号、営業時間を、ホームページと同じ表記にします。
  3. カテゴリを正しく選ぶ：業種に一番近いものをメインにします。
  4. 事業の説明とサービスを書く：何ができるか、どの地域に対応しているかを具体的に書きます。
  5. 写真を定期的に追加する：仕事の様子、施工事例、車両、建物の外観など。
  6. 口コミに返信する：良い口コミにはお礼を、厳しい口コミにも落ち着いて返信します。
  7. 投稿機能でお知らせを載せる：月に1〜2回でも、動いている会社だと伝わります。

登録や整え方のくわしい手順は、Googleマップで選ばれる会社の共通点でまとめています。

始めて最初の1か月でやること

やることが多く見えても、順番に進めれば1か月ほどで土台は整います。

時期やること
1週目Googleマップで自社を検索し、すでに情報が出ていないか確かめる。会社のアカウントで登録、またはオーナー確認の手続きをする。
2週目会社名、住所、電話番号、営業時間、カテゴリ、ホームページのURLを、ホームページと同じ表記で入れる。
3週目事業の説明とサービスを書く。外観、仕事の様子、事例、車両などの写真を10枚ほど載せる。
4週目最初の投稿を出す。最近の仕事を終えたお客様に、口コミをお願いしてみる。

はがきでオーナー確認をする場合は、届くまでに日数がかかります（Googleのヘルプでは通常14日以内とされています）。その間に、写真や説明文を準備しておくと、確認が済んだらすぐに載せられます。

写真の選び方

写真は、文章よりも先に目に入る情報です。次の点を意識して選ぶと、どんな会社かが伝わりやすくなります。

  • 建物の外観と入口：初めて来る人や配送の人が、場所を見つけやすくなります。看板が写っているとなお分かりやすいです。
  • 仕事の様子：現場で作業している様子、工場の中、トラックへの積み込みなど、「何をしている会社か」が一目で分かるもの。
  • 仕事の成果：施工事例、仕上がった製品など。取引先の名前やお客様の家が特定できるものは避けます。
  • 明るく、ぶれていない写真：スマホで撮った写真でも十分です。暗い写真は、明るい時間に撮り直しましょう。

口コミの集め方と返信のしかた

口コミは、Googleマップを見た人が依頼先を選ぶときの大きな判断材料です。決まりを守りながら、少しずつ増やしていきましょう。

集め方

  • 仕事が終わったタイミングでお願いする：納品や引き渡しのときに、「よろしければ感想を書いていただけると励みになります」と伝えます。
  • 書く画面へのリンクやQRコードを渡す：ビジネスプロフィールでは、口コミを書く画面へのリンクやQRコードを用意できます。メールや請求書に添えると、書いてもらいやすくなります。
  • すべてのお客様に同じようにお願いする：満足していそうな人だけを選んで頼むことは、Googleの決まりで禁止されています。

返信のしかた

  • 良い口コミ：お礼と、具体的に触れられていた点への一言を返します。
  • 厳しい口コミ：まず事実を社内で確かめます。そのうえで、言い訳をせず、落ち着いて、改善することや連絡先を伝えます。
  • 書かないこと：お客様の名前や個人の情報、宣伝の文句は書きません。

返信は、Googleの確認を経て表示されます。通常は10分以内ですが、長いと30日ほどかかることもあると案内されています。

無料相談Googleマップや検索で見つけてもらいたい方へ

Googleマップの登録・整備から、検索で見つけてもらうためのホームページづくりまでお手伝いします。

やってはいけないこと

早く上に出したいからといって、Googleの決まりに反することをすると、かえって逆効果になります。

  • 会社名に地域名や宣伝の言葉を足す：「〇〇工業｜〇〇市の外構工事」のような名前は、Googleのガイドラインで認められていません。実際に使っている名前を登録します。
  • 実際に仕事をしていない住所で登録する：バーチャルオフィスなどは登録できません。
  • 口コミを買う、見返りを渡して書いてもらう：お金や値引きと引き換えの口コミ、社員や関係者による口コミ、偽の口コミは禁止されています。
  • 良い口コミだけを選んで集める：満足していそうなお客様にだけ頼むことや、悪い口コミを書かないよう頼むことも、禁止されている行為にあたります。

決まりに反すると、口コミが消されたり、プロフィールの表示が制限されたりするおそれがあります。

業種ごとのポイント

  • 建設業：施工の写真と、対応している地域をしっかり載せます。「〇〇市 外構工事」のように、地域と工事の種類で探されることが多い業種です。
  • 工務店：施工事例の写真と口コミが特に見られます。完成見学会などのお知らせも、投稿機能で載せましょう。
  • 運送業：車両の写真、対応エリア、取り扱える荷物を書いておきます。ドライバーを募集している場合は、採用ページへの案内も役立ちます。
  • 製造業：工場の外観、設備、主な加工の内容を載せます。人が訪ねてこない場合でも、取引先が所在地や会社の様子を確かめるのに使われます。

お客様のところへ出向いて仕事をする会社は、住所を表示せず、対応している地域（サービス提供地域）を設定することもできます。Googleのヘルプでは、地域は最大20か所まで、範囲は拠点から車でおよそ2時間以内に収めるよう案内されています。

効果の見方

MEO対策の効果は、ビジネスプロフィールの「パフォーマンス」という画面で確かめられます（オーナー確認が必要です）。

  • どんな言葉で見つけてもらったか：狙っている「地域名＋業種」の言葉で見つけてもらえているかが分かります。
  • プロフィールが見られた数：Google検索とGoogleマップで、見た人の数です。
  • 電話、ホームページへのクリック、ルート検索の数：見た人が、実際に行動した数です。

「〇〇市 工務店」で何位か、という順位は、探す人の場所によって変わるため、自分の会社のパソコンで調べた順位だけでは判断できません。順位より、電話やホームページへのクリック、そして実際の問い合わせが増えているかを、数か月単位で見るのがおすすめです。

記録は、表計算ソフトに月ごとの数字を書き写すだけで十分です。「見られた数」「電話の数」「ホームページへのクリック」「その月の問い合わせの数」の4つを並べ、その月にしたこと（写真を10枚足した、説明を書き直した、など）をメモしておくと、何が効いたのかを後から振り返れます。問い合わせのときに「何で知りましたか？」と聞き、「Googleマップで見た」という答えを数えておくのも役に立ちます。

「MEO対策は意味がない」と言われる理由

MEO対策には、「やったけど意味がなかった」という声もあります。多いのは、次のような場合です。

  • 登録しただけで止まっている：情報が古いまま、写真も口コミへの返信もない状態では、選ばれにくくなります。
  • 探されていない言葉を狙っている：そもそもGoogleマップで探されることが少ない業種や言葉では、上に出ても問い合わせにつながりにくいです。
  • 順位だけを見ている：順位が上がっても、ホームページが古かったり、問い合わせ先が分かりにくかったりすると、そこで離れてしまいます。

MEO対策は、それだけで仕事が増える魔法ではありません。Googleマップで見つけてもらい、ホームページで信頼してもらい、問い合わせにつなげる。この流れのうちの、入口を整える取り組みだと考えると、期待とのずれが少なくなります。

Googleマップから来た人のために、ホームページで整えること

Googleマップで見つけてもらっても、最後に依頼するかどうかを決めるのは、ホームページを見たあとのことが多いです。制作する側として、次の点をよく確かめています。

  • Googleマップと同じ情報が書いてあるか：会社名、住所、電話番号、営業時間の表記をそろえます。
  • 対応している地域が書いてあるか：「〇〇市を中心に〇〇県全域」など、具体的に書きます。
  • 何ができるかがすぐ分かるか：トップページを開いて数秒で、主な仕事が分かるようにします。
  • スマホで問い合わせしやすいか：Googleマップから来た人がスマホで見ていることも考えて、電話番号をタップしてかけられるか、フォームが入力しやすいかを確かめます。
  • 事例やお知らせが新しいか：最後の更新が何年も前だと、「今もやっている会社かな」と不安にさせてしまいます。

ビジネスプロフィールに登録するホームページのURLは、トップページが基本です。問い合わせが少ないと感じたら、ホームページから問い合わせが来ない理由もあわせて見直してみてください。

MEOツールは必要か

MEO対策について調べると、口コミの返信や投稿をまとめて管理したり、順位を毎日記録したりする有料の道具（ツール）も出てきます。拠点がいくつもある会社には便利なこともありますが、拠点が1か所の中小企業なら、ビジネスプロフィールの管理画面と「パフォーマンス」の画面だけで、多くのことは足ります。まずは無料の範囲で続けてみて、手が回らなくなってから考えても遅くありません。

ツールを使う場合も、口コミへの返信の文章を自動で同じものにするのはおすすめしません。口コミを読んだ人には、決まり文句の返信はすぐに分かります。短くても、その口コミに合わせた言葉で返すほうが、会社の誠実さが伝わります。

業者に頼むときの費用の考え方

MEO対策を業者に頼む場合、料金の形はおもに次の2つです。

  • 月額固定：毎月決まった金額で、情報の整備や投稿、報告などを任せる形です。月に数万円ほどのサービスが多く見られます。
  • 成果報酬：決めた言葉で上位に表示された日だけ費用がかかる形です。上位に出ている間は費用がかかり続けるので、合計の金額を計算しておきましょう。

月々の金額だけでなく、初期費用があるか、最低何か月の契約か、を合わせて「契約期間の合計でいくらになるか」で比べると、判断しやすくなります。

見積りで確かめたいこと

  • 毎月、具体的に何をしてくれるのか：写真の追加、投稿、口コミへの返信、報告など、作業の中身を確かめます。
  • 契約の期間と、やめるときの条件：途中でやめた場合の費用もあわせて確かめます。
  • アカウントの持ち主は誰になるのか：ビジネスプロフィールのオーナーは自社のままにし、業者は「管理者」として加えてもらうのが安心です。
  • やめたときに何が残るのか：載せた写真や投稿、整えた情報が、そのまま自社に残るかを確かめます。

自分でやるか、頼むかの考え方

登録や情報の整備は、一度やってしまえば、あとは月に一度の見直しで十分なことが多いです。社内に担当できる人がいれば、まずは自分たちで始めてみるのがおすすめです。一方で、写真の追加や投稿を続ける時間がない、どこから手をつければいいか分からない、という場合は、人に頼むのも一つの方法です。

マツケンスタジオでは、Googleマップの登録や整備から手伝っています。お客様のGoogleアカウントを持ち主としたまま整えるので、あとから自社で管理を続けることもできます。

気をつけたい営業

  • 「Googleの公式」を名乗る電話：Googleから、MEOの契約を勧める営業の電話がかかってくることは基本的にありません。名乗り方に注意しましょう。
  • 「必ず1位にします」という約束：表示の順番は、探す人の場所や言葉で変わります。必ず1位になると約束することはできません。
  • 口コミを増やすという提案：お金と引き換えに口コミを書かせることや、偽の口コミは、Googleの決まりで禁止されています。違反すると、口コミが消されたり、表示に影響したりするおそれがあります。
  • 長い契約期間と高い解約金：契約の前に、期間と解約の条件を確認しましょう。

まとめ

MEO対策は、Googleマップで見つけてもらうための取り組みです。登録、情報の整備、写真、口コミへの返信、投稿と、多くのことは無料で自分たちでできます。会社名に言葉を足す、口コミを買うといった近道は、かえって逆効果です。効果は順位だけでなく、電話やホームページへのクリック、問い合わせの数で見ていきましょう。業者に頼む場合は、何をしてくれるのか、契約期間の合計はいくらか、持ち主は誰かを確かめてから決めましょう。そして、Googleマップから来た人が見るホームページも、一緒に整えておくことが大切です。AIに会社を紹介してもらうための考え方は、ChatGPTに自社を紹介してもらうには？でまとめています。

よくある質問

Q
MEO対策は、どのくらいで効果が出ますか？

情報を整えてすぐ変わることもあれば、口コミや写真が増えるにつれて少しずつ変わることもあります。数か月単位で続けるつもりで取り組むのがおすすめです。

Q
人が訪ねてこない業種でも、MEO対策は必要ですか？

必要です。工場や運送会社のように、お店として人が来ない業種でも、「地域名＋業種」で探されることは多くあります。住所を出さずに対応地域を設定する方法もあります。

Q
口コミが少ないのですが、どうすればいいですか？

仕事が終わったときに、お客様に口コミを書いてもらえるようお願いするのが基本です。お礼の品と引き換えにするなどのやり方は、Googleの決まりで禁止されています。

Q
MEOとホームページ、どちらを先に整えればいいですか？

どちらも大切ですが、Googleマップで見つけた人は次にホームページを見るので、ホームページが古いままだと、そこで離れてしまいます。両方を一緒に整えるのがおすすめです。

Q
MEO対策を業者に頼んでいる途中で、やめることはできますか？

契約の条件によります。契約の前に、最低の契約期間と、途中でやめるときの費用を確かめておきましょう。ビジネスプロフィールのオーナーを自社のままにしておけば、やめたあとも自社で管理を続けられます。

Q
お金を払えば、Googleマップで上に出せますか？

Googleは、お金を払って地域の検索結果の順位を上げる仕組みは受け付けていないと説明しています。情報を正しく保ち、写真や口コミへの返信を続けることが基本です。
