ドメインとサーバーとは？ホームページを持つ前に知っておきたい基本

ホームページを作ろうとすると、必ず出てくるのが「ドメイン」と「サーバー」という言葉です。見積りにも載っていますが、何のことか分からないまま、制作会社に任せている会社は少なくありません。

任せること自体は問題ありません。ただ、ドメインとサーバーは、ホームページとメールの土台です。仕組みと、誰の名義で契約しているかだけは、知っておくとあとで困りません。この記事では、専門の言葉をできるだけ使わずに、二つの違いと、つながる仕組み、選び方の基本を紹介します。

ドメインは「住所」、サーバーは「土地」

ホームページを一軒の建物にたとえると、次のようになります。

言葉たとえ役目
ドメイン住所ホームページの場所を示す名前。「example.co.jp」の部分
サーバー土地ホームページのデータを置いておく場所
ホームページ建物文章、写真、デザインなどの中身

土地（サーバー）を借りて建物（ホームページ）を建て、住所（ドメイン）を付けると、誰でも訪ねて来られるようになります。どれか一つが欠けても、ホームページは見られません。

大事なのは、住所と土地は別々に契約するものだということです。そのため、土地を引っ越しても、住所はそのまま使い続けられます。サーバーや制作会社を変えても、ドメインさえ手元にあれば、アドレスは変わりません。

ドメインとサーバーは、どうつながっているのか

住所と土地が別々なら、ドメインを打ち込んだ人が、どうやって正しいサーバーにたどり着くのでしょうか。ここで出てくるのが「IPアドレス」と「DNS」です。

IPアドレスは、サーバーの「番号」

インターネットにつながっている機械には、一台ずつ「203.0.113.10」のような数字の番号が付いています。これをIPアドレスと呼びます。機械どうしは、本当はこの番号で相手を探してやりとりしています。

ただ、数字の並びは人には覚えにくいものです。そこで、番号の代わりに、覚えやすい名前を付けられるようにしたのがドメインです。電話にたとえると、IPアドレスが電話番号、ドメインが電話帳に載っている会社名にあたります。

DNSは、名前と番号をつなぐ「電話帳」

ドメインとIPアドレスを結びつけているのが、DNS（ドメイン・ネーム・システム）という仕組みです。ホームページを見る流れは、次のようになります。

  1. 見る人が、ブラウザにアドレスを打ち込むか、検索結果を押します。
  2. ブラウザが、DNSに「このドメインのサーバーの番号は？」と問い合わせます。
  3. DNSが、ドメインに登録されているIPアドレスを答えます。
  4. ブラウザが、その番号のサーバーにつながり、ホームページのデータを受け取って表示します。

この問い合わせは一瞬で終わるので、見る人が気づくことはありません。

サーバーを引っ越すときに起きていること

サーバーを引っ越すときは、DNSに登録している「行き先の番号」を、新しいサーバーのものに書きかえます。電話帳の会社名はそのままで、電話番号だけを新しくするイメージです。ドメインの契約先の管理画面で、「ネームサーバー」や「DNSレコード」という項目を書きかえる作業がこれにあたります。

書きかえた情報が世界中に行きわたるまで、しばらく時間がかかることがあります。その間は、古いサーバーと新しいサーバーのどちらが表示されるか定まらないため、引っ越しの作業は、古いサーバーの契約が残っているうちに進めます。メールの行き先もDNSで決まっているので、ホームページと一緒に書きかえ忘れがないかを確かめます。

ドメインとURLの違い、ドメインのしくみ

URLは、ページまで含めた「番地」

ドメインとよく混同されるのが「URL」です。URLは、ドメインに加えて、どのページかまでを示したアドレス全体のことです。

部分例意味
通信の方式https://暗号化されたやりとりで開く、という指定
ドメイン（ホスト名）www.example.co.jpどのサーバーか
ページの場所/company/サーバーの中の、どのページか

住所にたとえると、ドメインが「建物の住所」、URLが「建物の住所と部屋番号」です。1つのドメインの下に、会社概要、事業内容、お問い合わせなど、たくさんのURLがあります。

ドメインは、右から順に大きな区分

ドメインは、点（ドット）で区切られた部分に分かれていて、右にいくほど大きな区分になります。住所を「日本・県・市・町」と大きい順に書くのとは逆向きです。

  • トップレベルドメイン（TLD）：いちばん右の部分。「.jp」「.com」など。「.jp」のように国ごとに割り当てられたものと、「.com」「.net」のように分野や目的で分けられたものがあります。
  • 第2レベル、第3レベル：その左に続く部分。「example.co.jp」では、「co」が会社であることを表す区分で、「example」が会社ごとに選ぶ名前です。
  • サブドメイン：取ったドメインの左に、自分で付け足す部分。「www」や、「recruit.example.co.jp」の「recruit」などです。ドメインを持っていれば、追加の費用なしに作れることがほとんどです。

ドメインは、メールアドレスにも使われる

会社のメールアドレスの「@」より後ろの部分も、ドメインです。ホームページと同じドメインを使うことで、「info@会社のドメイン」のようなアドレスを持てます。

つまり、ドメインの契約が切れると、ホームページが見られなくなるだけでなく、メールも届かなくなります。ホームページより、メールが止まるほうが、仕事への影響は大きいかもしれません。

独自ドメインと、無料のドメインの違い

自社のために取った、自社だけが使えるドメインを「独自ドメイン」と呼びます。一方で、無料のホームページ作成サービスやブログサービスでは、サービスの会社のドメインの一部を借りる形になることがあります。

形アドレスの例持ち主
独自ドメインexample.co.jp自社
サービスのサブドメインexample.サービス名.comサービスの会社
サービスのドメインの下のページサービス名.com/exampleサービスの会社

独自ドメインの良さ

  • サービスや制作会社を変えても、アドレスが変わらない：借りているドメインは、サービスをやめると使えなくなります。独自ドメインなら、引っ越し先でも同じアドレスを使えます。
  • 検索での評価を積み上げられる：長く使うほど、外からのリンクや検索での評価がそのドメインにたまっていきます。アドレスが変わると、それを引き継ぐ手間がかかります。
  • メールアドレスに会社名が入る：無料のメールアドレスより、取引先に会社として認識してもらいやすくなります。
  • 名刺や会社案内に載せても、見た目が整う：短く、会社名と結びついたアドレスは、それだけで信頼につながります。

取引先の調達担当者や、採用で応募を考える人は、名刺やメールのアドレスを見て、その会社のホームページを確かめます。BtoBの会社にとって、独自ドメインは、年に数千円ほどで持てる会社の看板だと考えてください。無料や月額制のサービスの注意点は、格安ホームページ制作・サブスク型のデメリットで紹介しています。

ドメインの種類と選び方

ドメインの最後の部分には、いくつかの種類があります。会社でよく使われるのは、次の3つです。

種類特徴
.co.jp日本で登記している会社が取れる。原則として1つの会社につき1つ
.jp日本に住所があれば、会社でも個人でも、いくつでも取れる
.com世界中の誰でも取れる。もっとも広く使われている

会社のホームページであれば、「.co.jp」が選ばれることが多くなっています。日本で登記している会社しか取れないため、アドレスを見ただけで、実在する会社だと伝わりやすいからです。個人事業主の場合は「.co.jp」を取れないので、「.jp」や「.com」から選びます。

「.co.jp」の主なルール

「.co.jp」を管理している日本レジストリサービス（JPRS）の公式情報では、次のように決められています。

  • 取れるのは、日本で登記している会社：株式会社、合同会社などのほか、日本で登記している外国の会社なども含まれます。
  • 原則として、1つの会社に1つ：社名の変更、合併、事業の譲り受けなどのときは、例外として2つ目を持てる場合があります。
  • 設立前でも、先に押さえられる：会社の設立や社名の変更を予定している場合は、「仮登録」の制度があり、6か月以内に登記などを済ませれば、そのまま使い続けられます。

「1社に1つ」なので、どの名前で取るかはとくに大切です。あとから別の名前の「.co.jp」に変えたくなっても、気軽には増やせません。事業ごと、商品ごとのホームページを持ちたい場合は、「.jp」や「.com」で別に取る方法もあります。

名前を決めるときのコツ

  • 会社名や屋号を、そのまま使う：覚えやすく、検索で見つけたときにも同じ会社だと分かります。
  • 短く、読み間違えにくくする：電話で伝えたり、名刺を見て打ち込んだりすることを考えます。
  • ローマ字のつづりを社内でそろえる：「shi」と「si」、「tsu」と「tu」、伸ばす音の書き方などで迷いやすいものです。名刺や英語の社名表記と合わせておきます。
  • まぎらわしい文字を避ける：「ー（ハイフン）」が多いもの、数字の「0」と英字の「o」、「1」と「l」が混ざるものは、伝え間違いのもとになります。
  • 長く使えるものにする：ドメインを途中で変えると、名刺、メールアドレス、検索での評価に影響が出ます。今の主力商品や地名だけを入れると、事業が広がったときに合わなくなることがあります。

独自ドメインを取る手順

  1. 使いたい名前の候補をいくつか出す：第一候補が取られていることもあるので、2〜3案を用意します。
  2. 空いているかを調べる：ドメインは、先に取った人のものになります。ドメインを扱っている会社のサイトで、名前を入れると調べられます。
  3. 契約する会社を決める：サーバーと同じ会社にまとめるか、別にするかを決めます。どちらでもホームページは動きます。
  4. 自社の名義で申し込む：登録者の名前は会社名にし、連絡先には、担当者が変わっても届く会社のメールアドレスを使います。「.co.jp」の場合は、登記の情報が必要になります。
  5. 自動更新と支払い方法を設定する：更新を忘れて止まるのを防ぐため、自動で更新される設定にしておきます。
  6. サーバーとつなぐ：DNSの設定で、ドメインの行き先をサーバーに向けます。ここは制作会社に任せてもかまいません。

サーバーの種類

中小企業のホームページでは、「レンタルサーバー（共用サーバー）」を使うことがほとんどです。1台のサーバーを多くの利用者で分け合う形で、費用を抑えられ、機械の管理もサーバーの会社が行ってくれます。

種類特徴向いているホームページ
レンタルサーバー（共用）1台を多くの利用者で分け合う。費用が安く、管理の手間が少ない会社案内、採用ページ、LPなど
専用サーバー・VPS1台、または仮想の1台を自社だけで使う。自由がきく分、設定や管理の知識がいる独自の仕組みを動かすサイト
クラウドのサービス使った分だけ払う形が多く、アクセスの増減に合わせて広げられるアクセスが多い、または大きく変わるサイト

会社案内が中心のホームページであれば、レンタルサーバーで十分です。

レンタルサーバーを選ぶポイント

レンタルサーバーは、料金の安さだけで選ぶと、あとで困ることがあります。会社のホームページとメールを預ける場所として、次の点を確かめます。

1. 無料のSSL証明書が使えるか

今のホームページは、暗号化（SSL化）が欠かせません。管理画面から無料の証明書を設定でき、自動で更新されるかを確かめます。くわしくは、「保護されていない通信」と出るのはなぜ？で紹介しています。

2. バックアップの仕組みがあるか

データを自動で控えておく仕組み（バックアップ）があるか、何日分残るか、戻すときに費用がかかるかを確かめます。操作の間違いや、不正に入り込まれたときに、元に戻せるかどうかがここで決まります。

3. メールが使いやすいか

中小企業では、ホームページと同じサーバーでメールを使うことがよくあります。メールアドレスを必要な数だけ作れるか、1人あたりの保存できる量は足りるか、迷惑メールを振り分ける機能があるかを見ます。

4. 表示の速さと、安定しているか

ページが表示されるまでに時間がかかると、見る人は待たずに離れてしまいます。速さを重視した設定があるか、障害やメンテナンスの情報をきちんと公開しているかを確かめます。

5. 困ったときの窓口

電話やメール、チャットなど、どの方法で、どの時間帯に問い合わせできるかを見ます。社内に詳しい人がいない会社ほど、ここが大切です。

6. 契約と支払いの形

月払いか年払いか、法人名義で契約できるか、請求書で払えるかなども、会社として使ううえでは確かめておきたいところです。WordPressを使う予定がある場合は、対応しているかも見ておきます（ホームページにWordPressは必要かで紹介しています）。

かかる費用の考え方

ドメインとサーバーには、制作費とは別に、持ち続けるための費用がかかります。

  • ドメイン：1年ごとに更新の費用がかかります。年に数千円ほどが目安で、種類によって変わります。取るときだけ安く、2年目からの更新費が高くなるものもあるので、更新の料金も見ておきます。
  • サーバー：月ごと、または年ごとに利用料がかかります。レンタルサーバーなら、月に数百円から数千円ほどのものが多く見られます。

制作会社の見積りに「管理費」として含まれている場合は、ドメイン代とサーバー代の実費に、更新や保守の作業費が足されています。何が含まれているかは、ホームページの見積りの見方を参考に確かめてください。毎月・毎年かかる費用の全体は、ホームページの維持費・管理費の相場で、制作費はホームページ制作の費用は何で決まる？で紹介しています。

一番大事なのは、誰の名義か

ドメインとサーバーで、もっとも気をつけたいのが名義です。制作会社が代わりに契約してくれることがありますが、そのときに、契約の名義が制作会社になっていることがあります。

名義が制作会社のままだと、次のようなときに困ります。

  • 制作会社を変えたいのに、ドメインを渡してもらえない
  • 制作会社と連絡がつかなくなり、更新の手続きができない
  • 知らないうちに契約が切れて、ホームページとメールが止まる

自社の名義で契約し、手続きや設定だけを制作会社に任せる形にしておけば、こうしたことは起こりません。すでに制作会社の名義になっている場合の進め方は、ホームページの制作会社を乗り換える手順で紹介しています。

今すぐ確かめておきたい6つのこと

すでにホームページを持っている会社は、次の6つが社内で分かるかを確かめてみてください。

  • ドメインの契約先：どの会社で契約しているか。
  • サーバーの契約先：どの会社のサーバーを使っているか。
  • 契約の名義：自社の名義か、制作会社の名義か。
  • 管理画面のIDとパスワード：社内の誰が持っているか。
  • 更新日と支払い方法：いつ更新で、誰のカードや口座から払っているか。
  • メールの設定先：メールがどのサーバーで動いているか。

担当していた人が退職して、誰も分からなくなっていた、ということはよくあります。分かった内容は、紙やファイルにまとめて、複数の人が見られるところに置いておきましょう。更新の案内が届くメールアドレスが、今も使われているものかどうかも、あわせて確かめます。

まとめ

ドメインはホームページの住所、サーバーはデータを置く土地です。二つはDNSという電話帳のような仕組みでつながっていて、別々に契約するものなので、サーバーや制作会社を変えても、ドメインがあればアドレスとメールアドレスは変わりません。

会社として長く使うなら、借りもののアドレスではなく、自社の独自ドメインを持つのがおすすめです。名前は短く、つづりに迷わないものを選び、レンタルサーバーは料金だけでなく、SSL、バックアップ、メール、窓口まで見て選びます。そして、ドメインは自社の名義で持ち、契約先と更新日を社内で分かるようにしておくことが大切です。マツケンスタジオでは、ドメインもサーバーもお客様の名義のまま、手続きからお手伝いしています。

よくある質問

Q
ドメインとサーバーは、同じ会社で契約したほうがいいですか？

どちらでもかまいません。同じ会社にまとめると、支払いと管理が一つで済みます。別々の会社で契約していても、DNSの設定でつなげば、ホームページは問題なく動きます。どちらの場合も、名義を自社にしておくことが大切です。

Q
ドメインの更新を忘れると、どうなりますか？

ホームページが見られなくなり、同じドメインを使っているメールも届かなくなります。期限のあと、一定の期間を過ぎると、ほかの人がそのドメインを取れるようになります。自動で更新される設定にしておくと安心です。

Q
ドメインは、あとから変えられますか？

変えられますが、おすすめはしません。名刺やパンフレット、メールアドレスを直す必要があり、検索での評価にも影響が出ます。最初に、長く使える名前を選んでおきましょう。

Q
ドメインとサーバーの契約は、自分でしないといけませんか？

手続きを制作会社に任せることはできます。その場合も、契約の名義は自社にして、管理画面のIDとパスワードを受け取っておきましょう。

Q
「.co.jp」は、1つの会社でいくつも取れますか？

原則として1つの会社に1つです。社名の変更や合併などのときは、例外として2つ目を持てる場合があります。事業ごとに別のホームページを持ちたいときは、「.jp」や「.com」で取る方法があります。

Q
無料のホームページ作成サービスのアドレスのままでも、問題ありませんか？

すぐに困ることはありませんが、サービスをやめるとアドレスが使えなくなり、それまでの検索での評価も引き継げません。会社として長く使うなら、早めに独自ドメインを取っておくのがおすすめです。
